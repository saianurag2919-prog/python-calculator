Python Calculator

Project Overview

A simple Basic Calculator Application developed using Python as part of my Python Development Internship at Pinnacle Labs Pvt. Ltd.

Features

* Addition
* Subtraction
* Multiplication
* Division
* User-friendly graphical interface

Technologies Used

* Python
* Tkinter

How to Run

1. Install Python on your computer.
2. Download the gui_calculator.py file.
3. Open Command Prompt or PowerShell in the project folder.
4. Run the following command:

python gui_calculator.py
